# 강사 피드백 질문 리스트 (확정 v1)

## 문서 목적

기능 정의서 작성을 마친 뒤, 구현에 들어가기 전 부트캠프 강사에게 서비스 기획과 기능 설계에 대한 피드백을 받기 위해 준비한 질문 리스트이다. 사용자가 초안에서 부트캠프 강사 관찰 경험 관련 질문만 다듬어 최종본으로 확정했다.

## 확정 질문

1. 개발 경험을 AI가 질문하면서 되짚어보고, 본인이 왜 그렇게 구현했는지 설명할 수 있도록 돕는 흐름이 실제 학습 효과가 있을 것으로 보이시나요?
2. 교육생들을 보시면서 "내가 한 것 중에 어떤 경험을 정리해야 할지 모르겠다"거나, "구현은 했는데 당시 왜 그렇게 결정했는지 잘 기억이 안 난다"고 어려워하는 경우가 실제로 자주 있었나요?
3. AI가 작성한 코드나 바이브 코딩으로 만든 결과물을 본인이 제대로 이해하거나 설명하지 못하는 경우도 자주 보셨나요? 이런 문제도 AI가 계속 질문하면서 스스로 설명하게 만드는 방식으로 어느 정도 해결할 수 있을까요?
4. "왜 이 기술을 선택했나요?", "다른 방법은 고려하지 않았나요?"처럼 계속 꼬리 질문을 하는 방식이 실제 교육생들이 면접이나 발표를 준비할 때 도움이 될까요?
5. Git 기록에서 변경 규모나 구현 복잡도, 기술적인 의사결정이 있었던 흔적 등을 보고 정리할 만한 경험을 먼저 추천해 주려고 하는데, 이런 기준이 실제로 교육생이 설명해 볼 가치가 있는 경험을 찾는 데 적절할까요? 추가로 중요하게 봐야 할 기준이 있을까요?

## 범위에서 제외한 항목

에듀테크 도메인 종사자 관점 평가, 기능적으로 추가하면 좋을 부분이나 개선이 필요한 부분 점검은 이번 피드백 세션 질문 리스트에 포함하지 않기로 결정했다. 필요할 경우 별도로 정리한다.
