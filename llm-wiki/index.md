# llm-wiki

## 핵심 질문

- 개발자는 자기 프로젝트 경험 중 무엇이 설명할 가치 있는지 스스로 선별하고 설명하는 데 실제로 어려움을 겪는가?
- Repository 근거 기반 AI 인터뷰가 이 어려움을 실제로 해결하는가?
- 사용자가 이 경험을 반복해서 쓸 만큼 가치 있다고 느끼는가?
