# 커밋 블랙리스트 실데이터 검증 기록

## 참조

- `raw/2026-08-20-커밋-블랙리스트-필터-구현.md`의 키워드 검증 후속 기록입니다.
- 검증 대상은 `andbread/Andbread_Frontend`의 `develop` 브랜치입니다.

## 검증 결과

- 전체 커밋 594개에 블랙리스트 규칙을 적용했습니다.
- `style` 키워드는 UI 구현과 퍼블리싱 커밋을 포맷팅으로 오분류했습니다.
- `정렬` 키워드는 알림 목록 정렬처럼 실제 기능을 구현한 커밋을 포맷팅으로 오분류했습니다.
- 두 키워드를 유지하면 37개의 커밋이 포맷팅으로 제외됩니다.

## 반영 사항

- 포맷팅 규칙에서 `style`과 `정렬`을 제거했습니다.
- 두 키워드가 포함된 실제 기능 커밋이 상세 조회 대상으로 남는 회귀 테스트를 추가했습니다.
- 나머지 포맷팅 키워드인 `format`, `lint`, `eslint`, `prettier`, `포맷`, `린트`는 유지했습니다.

## 확인 필요

- 나머지 블랙리스트 키워드는 다른 실제 Repository 데이터로 추가 검증할 필요가 있습니다.
