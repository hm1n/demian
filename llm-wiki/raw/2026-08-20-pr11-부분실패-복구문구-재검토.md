## 발견한 결함

부분 실패 안내는 복구 동작과 관계없이 전체 조회를 다시 시도한다고 단정했습니다. 그러나 인증 취소는 인증을 다시 진행해야 하고 Repository 미존재는 다른 Repository를 선택해야 하므로 안내 본문과 버튼이 서로 다른 행동을 제시했습니다.

이 결함은 `8626a2c` 이전의 인증 취소 경로에도 이미 있었습니다. `8626a2c`가 원인별 복구 동작을 단일 매핑으로 통합하면서 Repository 미존재 경로에도 같은 모순이 드러났습니다. 따라서 직전 수정이 결함을 새로 만든 것은 아니지만 노출 범위를 넓혔습니다.

## 처리 결정

복구 종류별 문구 분기는 추가하지 않았습니다. 모든 경로에서 부분 결과를 이어 쓰지 않고 필요한 복구를 마친 뒤 처음부터 조회한다는 공통 사실만 안내하도록 변경했습니다. Repository 미존재처럼 재시도가 아닌 복구 경로에서도 특정 버튼 동작과 모순되지 않는지 회귀 테스트로 고정했습니다.
