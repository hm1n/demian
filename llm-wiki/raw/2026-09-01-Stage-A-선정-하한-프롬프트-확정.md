# Stage A 선정 문단에 하한을 넣어 후보 0개를 없앤다

## 확정

**Stage A 시스템 프롬프트의 선정 문단에 하한과 입력의 성격을 넣었다.** 후보 0개가 사라졌다.

## 바꾼 문구

이전이다.

```
recommended가 true이거나 기여 항목에 맞는 묶음은 합쳐서 최대 N개까지만 고르세요. (...)
규모가 크다는 이유만으로 고르지 말고 설명할 거리가 있는 묶음을 고르세요.
```

이후다.

```
입력으로 들어온 묶음은 이미 저장소 전체에서 점수로 걸러낸 상위 후보입니다. 따라서 고를 것이 없는
입력이 아닙니다. recommended가 true이거나 기여 항목에 맞는 묶음을 합쳐서 최소 1개, 최대 N개
고르세요. (...) 고를 때는 규모가 큰 묶음보다 설명할 거리가 있는 묶음을 앞세우세요.
```

세 가지를 바꿨다. **입력이 점수 선별을 통과한 상위 후보라는 사실을 알리고**, **최소 1개라는 하한을
주고**, 선정을 억제하던 마지막 문장을 우선순위 문장으로 고쳤다.

## 결과

입력은 모두 같다. 커밋 141건, 점수 선별 후 12묶음, 후보 상한 5개, 기여 항목 0개다.

| 모델 | 문구 | 실행 | 선정 개수 | 후보 0개 |
| --- | --- | --- | --- | --- |
| `gemini-3.5-flash-lite` | 이전 | 4회 | 0, 0, 0, 0 | **4/4** |
| `gemini-3.5-flash-lite` | **하한** | 5회 | **5, 5, 5, 5, 5** | **0/5** |
| `gemini-3.1-flash-lite` | 이전 | 6회 | 0, 5, 5, 5, 5, 0 | **2/6** |
| `gemini-3.1-flash-lite` | **하한** | 7회 | **5, 5, 5, 5, 5, 3, 5** | **0/7** |

`gemini-3.5-flash-lite`는 네 번 모두 0개였던 것이 다섯 번 모두 5개가 됐다. `gemini-3.1-flash-lite`는
최소 3개이고 0개가 없다.

## 판정 1. 원인은 프롬프트였고 모델도 경로도 아니었다

세 가설을 차례로 배제했다.

1. **모델 가설.** 2순위 모델이 더 나빴다(0/4). 모델 교체로 풀리지 않았다.
2. **로컬 문구 가설.** 로컬 전용 문구를 프로덕션으로 올려도 `gemini-3.5-flash-lite`는 4회 모두 0개였다.
   되돌렸다.
3. **하한 가설.** 하한을 넣자 두 모델 모두 0개가 사라졌다. **엔드포인트를 바꾸지 않았다.** 네이티브
   `responseSchema` 경로 그대로다.

따라서 2026-08-28에 OpenAI 호환 경로가 후보를 골랐던 것은 경로 덕분이 아니라, 그 실행이 우연히 고른
회차였을 가능성이 크다. 각 경로를 1회만 실행했기 때문에 갈릴 수 없었다.

## 판정 2. 전 구간이 통과한다

`stage-b` 단계로 Stage A와 Stage B를 이어 돌렸다.

- Stage A 2,103밀리초, 예산의 3.8%, 판정 12/12, 누락 0, 중복 0, 후보 5개
- Stage B 4,570밀리초, 후보 묶음 5개를 커밋 30건으로 펼침, PR 5개 전부 커밋 2개 이상, 최종 후보 3개
- 선정된 후보에 관련 커밋 6개, 인용 파일 3개, 근거 문장 143자

**배선 후 처음으로 전 구간이 의미 있는 결과를 냈다.**

## 판정 3. 선정 개수의 분산은 줄었으나 남아 있다

`gemini-3.1-flash-lite`가 7회 중 1회 3개를 골랐다. 상한 5개를 늘 채우지는 않는다. 0개가 아니므로 화면이
비지는 않지만, **몇 개를 고르는지는 여전히 회차마다 다르다.**

## 남은 것

1. **선택 내용이 회차마다 같은지 확인하지 않았다.** 개수만 셌다. 같은 5개를 고르는지, 다른 5개를
   고르는지는 별도 확인이 필요하다.
2. **기여 항목이 있는 입력으로 재지 않았다.** `contribution_match` 경로가 아직 열리지 않았다.
3. **교육생 저장소로 재지 않았다.** 유료 등급으로 전환됐으므로 가능하다.
4. **하한 1개가 적절한 값인지 재지 않았다.** 상한 5개에 하한 1개다. 하한을 올리면 억지로 고르게 만들 수
   있어 올리지 않았다.
