# 경험 선택 기능 설계 세션 로그

## 문서 목적

"경험 선택" 기능을 설계하면서 논의하고 결정한 내용을 보존한다.

## 논의 내용

### 재선택 허용 여부

경험을 선택해 인터뷰를 시작한 뒤, 사용자가 다른 후보로 되돌아가거나 재선택할 수 있어야 하는지 논의했다. 당연히 재선택할 수 있어야 하고, 한 경험에서 진행하던 대화는 그대로 유지되어야 한다는 결론이 나왔다. 사용자가 잘못 고른 경우나 여러 경험을 다 인터뷰해보고 싶은 경우를 고려한 결정이다.

### 세션 유지 범위

경험별 대화 세션을 유지하는 범위를 방문 중에만 유지하는 안과 서버에 저장해 재방문해도 유지하는 안을 비교했다. 서버에 저장해 재방문해도 유지하는 것으로 결정했다. 브라우저를 닫았다가 다시 열어도 이전에 진행하던 경험별 대화를 이어서 볼 수 있어야 한다는 판단이다.

## 결정 사항 요약

- 사용자는 인터뷰 도중이나 이후에도 언제든 다른 경험 후보로 돌아가 재선택할 수 있다.
- 경험 후보마다 독립된 대화 세션을 서버에 저장한다. 다른 경험으로 전환해도 이전 세션의 대화 내용은 그대로 보존된다.
- 경험을 다시 선택하면 저장된 대화 이력을 불러와 이어서 진행한다. 처음 선택하는 경험이면 새 세션을 만든다.
- 이 기능은 세션 생성과 전환, 유지까지 담당한다. 실제 질문을 생성하는 일은 AI 질문 기능이 담당한다.

## 확인 필요

- 스트리밍 응답이 진행되는 도중 다른 경험으로 전환할 때 처리 방식
- 세션 데이터의 보관 기간과 삭제 정책
- 여러 탭에서 같은 경험 세션을 동시에 열었을 때 처리 방식
