## 제목 형식

```
<type>: <제목>
```

- 제목은 한국어로 작성합니다.
- 제목은 **명사형으로 끝냅니다.** `~한다`, `~합니다`, `~했다` 같은 서술형 종결어미를 쓰지 않습니다.
- 제목 끝에 마침표를 쓰지 않습니다.
- 제목 한 줄로 작성합니다. 지금까지의 이력에는 본문이 없습니다.

명사형 종결에 쓰는 표현의 예시입니다. 추가, 제거, 수정, 보완, 정의, 구현, 기록, 정리, 통합, 보존, 축소, 갱신, 판별, 명확화.

### 대조 예시

아래는 실제로 머지 전에 재작성이 필요했던 제목입니다.

| 쓰지 않습니다 | 씁니다 |
| --- | --- |
| `feat: 경험 후보 출력 스키마를 정의한다` | `feat: 경험 후보 출력 스키마 정의` |
| `feat: PAT 세션 쿠키 인증 경계를 추가한다` | `feat: PAT 세션 쿠키 인증 경계 추가` |
| `fix: 중복 경험 후보를 거부한다` | `fix: 중복 경험 후보 거부` |
| `fix: 자체 리뷰에서 인증 복구 경계를 보완한다` | `fix: 자체 리뷰 인증 복구 경계 보완` |
| `docs: 재검증 후속 항목을 기록한다` | `docs: 재검증 후속 항목 기록` |
