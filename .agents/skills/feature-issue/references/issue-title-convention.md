## Issue 제목 규칙

Issue 제목은 아래 컨벤션을 따릅니다.

```text
[{라벨}/{도메인}] 이슈명
```

예시

```text
[enhancement/github-repo] GitHub 저장소 연결
[bug/streaming] 스트리밍 재연결 시 메시지 중복 표시
[documentation/llm-wiki] 인터뷰 설계 원칙 문서화
```

제목 생성 규칙은 다음과 같습니다.

- `{라벨}`은 현재 레포지토리에 등록된 GitHub Label의 영문 이름을 그대로 사용합니다.
- `{도메인}`은 작업 대상이 되는 기능 또는 영역을 대표하는 영문 키워드를 사용합니다. (예: `github-repo`, `streaming`, `interview`)
- `이슈명`은 작업 내용을 이해하기 쉬운 한국어로 작성합니다.
